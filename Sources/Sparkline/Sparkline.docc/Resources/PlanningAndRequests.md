# Planning and Requests

Where to go to ask for something, ask about something, or see what's coming next.

## Channels

| Resource | Use it for |
|---|---|
| **Submit a Request** | The intake form for new components, tokens or changes to the system. Start here before any work is scoped. |
| **AMA** | The Teams channel for development and UI questions. Best for quick clarification that doesn't need a formal request. |
| **Roadmap** | The current Design System roadmap: what's in progress, what's next and what's been deprioritized. |
| **PI Planning** | Notes and outputs from the most recent Program Increment planning session, including sequencing and dependencies. |
| **Sprint Updates** | A running log of what shipped each sprint, so partner teams can track progress without attending every ceremony. |

## Reporting a gap

When an app needs something Sparkline doesn't have, build it locally with semantic tokens, mark it with a `// Not in Sparkline yet:` comment, and submit a request so the Design System can decide whether to add it.
