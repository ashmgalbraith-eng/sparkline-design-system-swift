# Communication and Enforcement

The pull request is the single source of truth.

## Overview

> Important: Decisions made outside of the pull request do not count.

## Rules

1. All feedback happens in the pull request for that change.
2. No decision-making in Teams chats or side-thread approvals.
3. Decisions are documented in the pull request.
4. No one modifies Design System repositories without Design System approval.
5. Unauthorized changes are reverted.

## Enforcement

> Warning: Violations include catalog updates without a pull request, direct repository changes and bypassing the process. Violations are reverted and must be resubmitted through the proper channels.

## Teams channels

| Channel | Purpose |
|---|---|
| AMA | Questions about development and UI |
| Announcements | Release updates |
| Resources | Shared materials |
